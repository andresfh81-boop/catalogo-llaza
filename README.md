# Catálogo Llaza (app instalable)

Página para instalar el Catálogo Llaza como app (con su nombre e icono). Solo muestra a pantalla completa la app de Google Apps Script del Catálogo (repositorio privado `catalogo-llaza-app`), porque Chrome no deja instalar `script.google.com`.

Enlace: https://andresfh81-boop.github.io/catalogo-llaza/

Los iconos se generan con `icon/make_icon.py` del repositorio `catalogo-llaza-app`.
